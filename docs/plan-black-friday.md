## 风险与预案

| 风险 | 预案 |
| --- | --- |
| Chrome 扩展审核赶不上 | 提供“加载已解压的扩展”安装说明和 Docker 采集器；你自己的采集端先覆盖 DMV 三家店 |
| 采集端太少，覆盖不了门店 | 上线时只承诺有采集端覆盖的门店，页面显示每家店的最后更新时间；鼓励用户“开一个采集端解锁你附近的门店” |
| 黑五期间 Micro Center 收紧拦截 | 采集端遇拦即停，不对抗；页面显示“数据暂停更新”；其他来源照常 |
| 恶意采集端上传假数据 | 服务器解析原始页面、异常价格待确认、信任分、可吊销 token |
| 新域名邮件进垃圾箱 | 23 日前完成 SPF / DKIM / DMARC，先给自己和朋友发几天；上线初期只发每日摘要和即时提醒，不发营销内容 |
| Best Buy / Woot key 没下来 | 先用 Micro Center + DealNews 上线，key 到了再接 |
| 时间不够 | 按“黑五前不做”的顺序继续往后砍；底线是采集 + feed + 一条规则 + 每日摘要 |
